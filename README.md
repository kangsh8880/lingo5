# 입말 (Ipmal) — 5개국어 말하기·학습

베트남어·영어·중국어·일본어·한국어 문장을 간격반복 카드, 퀴즈, 단어장으로 학습하는 웹앱입니다.

## 기능
- **카드학습**: 알아요/애매/모름 평가에 따라 복습 주기 1·2·4·7·15·30일 자동 배정, 하루 신규 카드 수 설정
- **퀴즈**: 뜻 고르기 / 표현 고르기 / 듣고 고르기, 오답은 오늘 복습 카드에 자동 추가
- **단어장**: 검색·분류·즐겨찾기, 내 문장 추가, CSV 내보내기/가져오기
- **학습현황**: 오늘 학습·복습 예정·습득 문장·정답률·연속 학습일, 지표별 추이 차트(기간 필터는 차트에만 적용)
- **설정**: 학습/뜻 언어, 카드 앞면, 음성 속도, 베트남어 GAS 음성 프록시 URL, 백업·복원

## 추가 기능 (2026-11-09)
- 따라 말하기: 카드학습·퀴즈에서 듣고 따라 말하면 일치율(%)과 틀린 부분 표시, 80% 이상 통과
- 받아쓰기: 듣고 입력 → 채점 (베트남어 성조 누락 = 부분 정답, 중국어 병음·일본어 로마자 입력 가능)
- 취약 문장 TOP 10 + 집중 복습, 퀴즈 출제 범위 '취약 문장'
- PWA: 홈 화면 설치·오프라인 카드학습 (manifest.webmanifest, sw.js, icons/)
- 번역·베트남어 음성: 일일어학학습 GAS 웹앱 우선 사용 (GAS Code.gs에 action=translate 추가 필요)

## 문장 원본 (Google 시트, 2026-11-09)
- 원본: Google 시트 '5개국어 학습 문장 (원본)' — GAS `setupPhraseSheet()`가 data/phrases_master.csv로 최초 1회 생성
- 메일(GAS)과 앱 모두 시트(사용=Y)를 읽음 → 시트만 고치면 다음 메일·앱 실행 시 반영
- 앱: GAS `?action=phrases` → 브라우저 캐시 → js/data.js(내장) 순으로 사용
- 개인 '내 문장'은 각 브라우저에만 저장 (시트와 별개)

## CSV 형식
`cat,ko,vi,en,zh,zh_pron,ja,ja_pron` — 첫 행은 머리글, UTF-8.

## 베트남어 음성 프록시
설정 > 베트남어 GAS 음성 프록시 URL에 `doGet(e)`가 `e.parameter.text`를 받아 MP3 base64(문자열 또는 `{"audio":"..."}`)를 반환하는 웹앱 URL을 넣으면 모바일에서 우선 사용합니다.
