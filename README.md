# 5개국어 학습카드

베트남어·영어·중국어·일본어·한국어 문장을 간격반복 카드, 퀴즈, 단어장으로 학습하는 웹앱입니다.

## 기능
- **카드학습**: 알아요/애매/모름 평가에 따라 복습 주기 1·2·4·7·15·30일 자동 배정, 하루 신규 카드 수 설정
- **퀴즈**: 뜻 고르기 / 표현 고르기 / 듣고 고르기, 오답은 오늘 복습 카드에 자동 추가
- **단어장**: 검색·분류·즐겨찾기, 내 문장 추가, CSV 내보내기/가져오기
- **학습현황**: 오늘 학습·복습 예정·습득 문장·정답률·연속 학습일, 지표별 추이 차트(기간 필터는 차트에만 적용)
- **설정**: 학습/뜻 언어, 카드 앞면, 음성 속도, 베트남어 GAS 음성 프록시 URL, 백업·복원

## 파일 구조
```
index.html
css/style.css
js/data.js    기본 문장 60개 (6개 분류)
js/store.js   브라우저 저장
js/srs.js     간격반복 엔진
js/tts.js     음성 재생 (괄호 제거, 베트남어 환경별 분기, 이중 재생 방지)
js/app.js     화면 로직
```

## CSV 형식
`cat,ko,vi,en,zh,zh_pron,ja,ja_pron` — 첫 행은 머리글, UTF-8.

## 베트남어 음성 프록시
설정 > 베트남어 GAS 음성 프록시 URL에 `doGet(e)`가 `e.parameter.text`를 받아 MP3 base64(문자열 또는 `{"audio":"..."}`)를 반환하는 웹앱 URL을 넣으면 모바일에서 우선 사용합니다.
